## Tips for Using Locations

### 1. Use Exact Names
✓ "Dar es Salaam" (correct)
✗ "Dar" (won't work)
✗ "DSM" (won't work)

### 2. Case Doesn't Matter
All these work:
- "Morogoro"
- "morogoro"
- "MOROGORO"

### 3. Check Spelling
Common mistakes:
- "Dodoma" not "Dadoma"
- "Mbeya" not "Mbeya"
- "Zanzibar City" not "Zanzibar"

### 4. Use Full Names
- "Dar es Salaam" not "Dar"
- "Zanzibar City" not "Zanzibar"
- "Stone Town" for Zanzibar old city

### 5. Add Remarks
Always add remarks to explain why vehicle is at that location:
- "Refueling stop"
- "Driver rest break"
- "Partial delivery"
- "Customs clearance"
- "Traffic delay"

## What Happens After Update

1. Vehicle immediately jumps to the location on map
2. Speed resets to 0 (stopped)
3. Customer sees updated location
4. Tracking event added to timeline
5. Vehicle continues normal movement after update

## Troubleshooting

### Location Not Recognized
**Problem**: "Location not found" error
**Solution**: Check spelling, use exact name from list above

### Vehicle Doesn't Move
**Problem**: Vehicle stuck at location
**Solution**: This is normal - vehicle will resume movement automatically

### Wrong Location
**Problem**: Vehicle jumped to wrong place
**Solution**: Create new update with correct location
